## 🌍 The Problem We're Solving

Every day, millions of people in developing regions are on the front lines of the climate crisis — planting trees, clearing plastic waste, maintaining clean energy infrastructure. Yet they receive **little to no economic reward** for this work.

Meanwhile, the global carbon economy generates billions in value — most of which never reaches the communities doing the actual work.

**EcoTask is changing that.**

---

## 💡 What Is EcoTask?

EcoTask is an open-source, mobile-first **decentralized application (dApp)** that connects environmental action to real economic value.

Users complete climate-action micro-tasks, submit verifiable proof, and receive **stablecoins or ECO tokens** — directly to their mobile wallets, with no bank account required.

```
📋 Browse Tasks  →  ✅ Complete & Submit Proof  →  🔍 Get Verified  →  💰 Earn Rewards
```

### 🌿 Example Tasks

| Task | Reward Type |
|------|------------|
| 🌳 Plant trees & saplings | ECO tokens |
| ♻️ Collect & sort plastic waste | USDC stablecoin |
| ☀️ Operate solar charging stations | ECO tokens |
| 🌾 Biochar production for carbon sequestration | ECO + carbon credits |
| 💧 Water source maintenance & reporting | ECO tokens |

## ⚙️ How It Works

```
┌─────────────┐     ┌──────────────┐     ┌───────────────┐     ┌──────────────┐
│  Browse     │────▶│  Complete    │────▶│   Submit      │────▶│   Receive    │
│  Tasks      │     │  Task        │     │ Photo + GPS   │     │   Reward     │
└─────────────┘     └──────────────┘     └───────────────┘     └──────────────┘
                                                │
                                                ▼
                                      ┌───────────────────┐
                                      │  On-chain         │
                                      │  Verification     │
                                      │  (Community +     │
                                      │   Oracle)         │
                                      └───────────────────┘
```

1. **Create a Wallet** — Sign up with a Stellar wallet via the EcoTask mobile app, no bank account needed
2. **Pick a Task** — Browse available climate-action tasks near you or globally
3. **Do the Work** — Complete the task in the real world
4. **Submit Proof** — Upload photo evidence and GPS coordinates
5. **Get Verified** — Community validators and on-chain oracles confirm the work
6. **Earn Instantly** — Receive ECO tokens or USDC directly to your wallet

## 🔗 Why Stellar?

We chose Stellar because it was built for exactly this kind of use case:

- ⚡ **3–5 second finality** — Rewards arrive almost instantly
- 💸 **Near-zero fees** — Micro-payments are actually viable
- 🌐 **Emerging market DNA** — Designed for financial access in developing regions
- 🪙 **Native stablecoin support** — USDC built in, no wrapping needed
- 🛠️ **Soroban smart contracts** — Programmable, auditable reward logic

---

## 🪙 Token Economy

EcoTask runs on a dual-token model:

| Token | Type | Use Case |
|-------|------|----------|
| `ECO` | Custom Stellar asset | Earned by completing tasks; governance voting |
| `USDC` | Stablecoin | Optional stable payout for task rewards |

- ECO token supply is tied directly to **verified environmental impact**
- Token holders gain **governance rights** to vote on new task types and platform rules
- Future integration with **carbon credit markets** to create a real carbon economy loop
